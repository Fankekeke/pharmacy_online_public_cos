# 基于 SpringBoot + Vue  的药房在线开单销售管理系统

药店医生工作台 · 平台管理后台 | 电子处方 · 批次库存 · 效期预警 · 在线开单 · 药品追溯

本项目是一套面向**连锁药房/单体药房**的在线开单销售管理平台，采用前后端分离架构，覆盖**管理员（平台）、药店医生、终端用户**三类核心角色。系统围绕"用户在线购药/处方上传→药师审方→在线开单→库存扣减→物流配送→用户签收评价"的核心业务流程设计，同时集成采购管理、供应商管理、批次库存、效期预警、电子处方流转等模块，符合《药品经营质量管理规范》（GSP）与《处方药网络零售合规指南》要求，构建合规、高效的医药零售数字化平台。

## 核心特性

- **电子处方合规流转**：严格遵循"先诊断、后开方、再售药"原则，支持处方上传/在线问诊开方→执业药师审核→处方绑定订单→调配发药的全流程闭环，严禁AI替代审方，处方全程留痕可追溯。
- **GSP合规批次库存管理**：药品入库必须记录生产批号、生产日期、有效期至，库存按"药店+药品+批次"三维管理，支持FEFO（先到期先出）出库策略，近效期自动分级预警，过期药品自动停售。
- **智能采购与供应链协同**：根据库存预警与销售数据自动生成采购建议，支持供应商资质管理、采购订单跟踪、采购物流追踪，形成完整的供应链闭环。
- **多维度数据统计**：管理员端提供数据看板，展示销售排行、员工绩效、库存周转、处方审核量、营收统计等多维度图表，支持运营决策。

## 功能模块概览

## 管理员端

管理员为平台运营中枢，负责全局管控与调度：

### 用户与药店管理

- **用户管理**：管理注册用户（终端消费者），包括用户ID、姓名、手机号、实名认证状态、注册时间、账户状态，支持用户信息查询与账户管理。
- **药店管理**：管理入驻药店，包括药店ID、药店名称、地址、联系人、联系电话、《药品经营许可证》资质、营业状态、入驻时间，支持药店审核、冻结/解冻。
- **员工管理**：管理各药店员工信息，包括员工ID、所属药店、姓名、岗位（执业药师/店员/库管等）、执业资格、账户状态，支持员工增删改查与权限分配。
- **管理员管理**：管理平台管理员账号，包括管理员ID、用户名、姓名、角色、最后登录时间、账户状态，支持管理员增删改查与权限配置。

### 药品与库存

- **药品管理**：管理全平台药品库，包括药品ID、通用名、商品名、规格、剂型、批准文号、生产厂家、处方药/OTC标识、零售价、会员价、存储条件、上下架状态，支持药品增删改查与批量导入。
- **供应商管理**：管理药品供应商信息，包括供应商ID、供应商名称、联系人、联系电话、供应品类、《药品经营许可证》资质、合作状态、信用评级，支持供应商增删改查。
- **供应采购/药品采购**：管理员发起药品采购订单，选择供应商、采购药品、数量、单价、批次信息（批号/生产日期/有效期）、期望到货时间，生成采购单，支持采购全流程跟踪。
- **采购记录**：查看全平台采购记录，包括采购单号、供应商、采购药品、数量、金额、采购状态（待发货/运输中/已到货/已入库）、采购时间，支持采购单详情查看。
- **采购物流**：跟踪采购订单的物流状态，包括物流单号、物流公司、当前位置、预计到货时间，支持物流轨迹查看与异常标记。
- **库存统计**：查看全平台库存汇总数据，包括各药店库存总量、库存金额、库存周转率、品类分布等统计信息。
- **药店库存**：查看各药店的批次库存详情，包括药店名称、药品名称、批号、库存数量、生产日期、到期日期、库位信息，支持库存查询与调拨。
- **库房预警**：查看全平台库存预警信息，包括低库存预警（低于安全库存阈值）、积压预警（库存过高），支持预警处理与补货建议生成。
- **保质期预警**：查看临近保质期的药品批次，包括药品名称、批号、到期日期、剩余天数、所属药店、预警等级（黄色/橙色/红色），支持临期药品处理与FEFO出库策略配置。

### 订单与物流

- **订单信息**：查看全平台订单，包括订单号、下单用户、所属药店、药品明细、订单金额、订单状态（待付款/待审方/待发货/运输中/已签收/已取消/已退款）、下单时间、处方信息，支持订单详情查看、手动改派、订单取消、退款处理。
- **订单详情**：查看订单完整信息，包括用户信息、药品明细、处方信息、支付信息、物流信息、操作日志，支持订单全链路追踪。
- **物流信息**：查看订单物流配送状态，包括物流单号、物流公司、配送员、当前位置、预计送达时间，支持物流轨迹查看。
- **缴费记录**：查看全平台缴费/支付记录，包括订单号、支付金额、支付方式（微信/支付宝/银行卡/医保）、支付时间、支付状态，支持对账与异常支付处理。

### 评价与数据

- **订单评价**：查看用户对订单/药品/物流服务的评价，包括评价内容、评分、评价图片、关联订单，支持评价审核与违规评价处理。
- **公告管理**：发布与管理平台公告，包括公告标题、内容、类型（系统通知/活动公告/政策更新/用药提醒）、发布时间、置顶状态，支持公告编辑与删除。
- **数据统计**：综合数据看板，展示核心运营指标（今日订单数/待审方数/本月营收/库存预警数/处方审核量/药店入驻数），支持销售趋势、药店绩效对比、药品销量排行、处方审核统计等多维度图表展示。
- **销售排行**：统计药品销售排行，包括畅销药品TOP榜、各药店销售额排行、各品类销售占比，支持按时间段筛选。
- **员工统计**：统计员工绩效数据，包括各药店员工开单量、处方审核量、服务评价、销售业绩，支持员工绩效排行。
- **销售统计**：多维度销售统计分析，包括按时间段/药店/品类/药品的销售数据汇总，支持销售额、销售量、毛利分析，支持报表导出。

### 处方管理

- **电子处方**：查看全平台电子处方记录，包括处方号、开方医生、患者信息、处方药品、审核药师、审核状态（待审核/已通过/已驳回）、开方时间，支持处方详情查看与合规审计。

## 药店医生端

药店医生通过工作台进行处方开具与店内运营管理：

### 账户与店铺

- **店内管理**：查看本店基本信息，包括药店名称、地址、营业时间、资质信息，支持店铺信息维护。
- **员工管理**：管理本店员工信息，包括员工姓名、岗位、执业资格、账户状态，支持员工增删改查与排班管理。

### 处方与订单

- **电子处方**：在线开具电子处方，包括患者信息登记、症状描述、诊断结果、处方药品选择、用法用量、注意事项，提交后进入药师审核流程；同时可查看本店处方记录与审核状态。
- **订单管理**：查看本店订单，包括订单号、下单用户、药品明细、订单金额、订单状态、处方信息，支持订单处理（确认订单/审核处方/发货/退款）。
- **订单物流**：查看本店订单的物流配送状态，包括物流单号、配送员、当前位置、预计送达时间，支持物流轨迹查看。
- **订单评价**：查看用户对本店订单/药品的评价，包括评价内容、评分，支持评价回复。

### 库存与采购

- **店内库存**：查看本店各药品的批次库存情况，包括药品名称、批号、库存数量、生产日期、到期日期、库位信息，支持库存盘点与库存调整。
- **库存统计**：查看本店库存统计数据，包括库存总量、库存金额、近效期药品数量、低库存药品数量。
- **库存预警**：查看本店库存预警药品，包括药品名称、当前库存、安全库存阈值，支持一键生成补货/采购申请。
- **保质期预警**：查看本店临近保质期的药品批次，包括药品名称、批号、到期日期、剩余天数，支持临期药品促销处理与FEFO出库。

## 用户小程序端

用户通过小程序进行药品选购与订单管理：

### 账户与个人

- **账户注册登录**：支持手机号+验证码注册与登录，支持微信授权一键登录，处方药购买需完成实名认证，支持找回密码。
- **个人信息**：查看与编辑个人基本信息，包括姓名、手机号、头像、性别、身份证号（实名认证）、过敏史、常用用药记录，支持信息修改。
- **我的信息**：综合查看个人账户信息，包括积分余额、会员等级、优惠券、健康档案等。

### 购药与订单

- **药品购买**：浏览药品列表，按品类筛选，查看药品详情（通用名、规格、生产厂家、用法用量、禁忌、价格、库存），OTC药品可直接加入购物车下单，处方药需上传处方或在线问诊开方后方可购买，支持在线支付（微信/支付宝/医保）。
- **我的订单**：查看个人订单列表，包括全部/待付款/待审方/待发货/运输中/已完成/已取消订单，支持订单详情查看、物流轨迹追踪、取消订单、申请退款。
- **支付结果**：查看订单支付结果，包括支付金额、支付方式、支付时间、支付状态。
- **缴费记录**：查看个人历史缴费记录，包括订单号、支付金额、支付方式、支付时间，支持记录查询与下载。
- **订单评价**：对已完成的订单进行评价，包括药品评分、物流服务评分、评价内容、评价图片，支持追加评价。

### 处方与通知

- **药品处方**：查看个人历史处方记录，包括处方号、开方医生、处方药品、用法用量、开方时间、审核状态，支持处方详情查看与复诊续方。
- **消息通知**：接收订单状态变更通知、处方审核结果通知、物流更新通知、用药提醒、促销活动推送等，支持消息列表查看与已读标记。
